FIRST Robotics 2025 Season Robot Code(Team 4998)

This is the code for Team TESLA(4998)'s 2025 robot. I was the lead programmer on the team and wrote this solely. This program uses Java and uses an object-oriented framework. This program allows the operator to control the robot with input from a console controller and to also move autonomously. I implemented pathplanning and vision software in this project, and retrieved data from sensors on the robot and used it to adjust the robot's position or actions.
